# 统一权限管理系统实现设计记录

日期：2026 年 10 月 8 日

行为基线为需求规格 2.1，源码边界以分析与设计指南 2.0 为准。实现使用 Java 21、Spring Boot 3.5.16 和 OIDC 授权码流程。

平台包含六个业务包。每个包通过 `api` 子包公开不可变事实与能力，持久化实体和 Repository 保持在本模块内部。`application` 只协调跨模块用例，不拥有业务数据。

认证和统一会话由 `identity` 维护。系统登记及 OIDC 客户端配置属于 `integration`。登录结果通过框架兑换，业务权限由 `authorization` 实时判断；ID Token 不代表操作权限。

数据库使用 Flyway 迁移和 JPA 校验。每员工每系统单角色通过唯一键和版本冲突检测维护；管理变更及审计在同一事务提交。数据库、接口契约和并发细节随对应实现补充，并通过真实 MySQL 测试验证。

初始化分别提供基础、演示及压测模式。演示配置和压测副本不改写教师提供的 Excel。数据库固定分为 `upms`、`upms_test` 和 `upms_load`，测试与压测不得指向演示库。
