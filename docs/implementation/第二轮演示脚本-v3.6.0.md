# 第二轮演示脚本 v3.6.0

1. 打开权限后台、课程入口、Swagger UI 和 JaCoCo。
2. 使用 `POST /auth/login` 提交 `systems: ["rbac", "course-project-management"]`，展示 JWT 的 aud 列表和 `GET /auth/me`。
3. 调用 `GET /auth/departments` 展开根部门，再调用 `/auth/departments/{departmentId}/users` 查询候选人，展示响应没有手机号和邮箱。
4. 调用 `GET /auth/users/{userId}` 展示工号和姓名。使用课程管理员令牌访问 `GET /auth/api-permissions/createTerm`，再用 viewer 访问并展示 `allowed: false`。
5. 打开课程入口，访问 `/me`、学期列表和课程详情。使用 viewer 新建学期，接口返回 403。
6. 展示角色继承、有效权限并集、解除继承和独立界面权限禁用。
7. 展示 `api/*/dto`、`api/*/vo`、`IdentityDirectoryService`、`UnifiedIdentityClient`、`ApiAuthorityClient`，说明 Controller 校验输入，Service 处理权限和业务规则，Infrastructure 处理外部 HTTP、SQL 和日志。
8. 展示结构化和 DDD 两个实现的同一套契约测试。课程联调证据见 [identity-integration-v3.6.0.json](identity-integration-v3.6.0.json)。
