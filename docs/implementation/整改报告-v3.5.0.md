# v3.6.0 整改报告

2026-11-18 完成第二轮检查所需的 RBAC1 双实现、图文补充和线上验证。用户、角色各属于单个部门；管理本部门直接成员；平台自身和老师课程系统统一接入 RBAC。业务库为八张业务表及一张技术会话表。

## 核查与实现

| 检查项 | 本轮结果 |
| --- | --- |
| RBAC1 | 新增同部门角色继承，支持多级、多路径、有效权限去重及实时撤权。自环和间接环返回 409；跨部门关联返回 403。事务内锁定部门行，防止并发反向连边形成环。 |
| 双实现 | StructuredRoleService 用事务脚本执行防环；DddRoleService 交给 RoleHierarchy 领域对象判断。共用 RoleUseCase、ManagementStore、数据库与前端，通过启动配置切换。 |
| 界面权限 | 配置继承使用独立 ui.role.inheritance 码；菜单和按钮缺码时禁用。API 继续检查 role.manage 及部门范围。迁移 V3 初始化新增界面码。 |
| 接口文档 | Swagger UI 列出全部 44 个平台 HTTP 操作，生成时核对 Controller 映射。修复文档页图标及 JaCoCo 脚本的 CSP 兼容问题。 |
| 对象拷贝和规范 | 延续 CloneFactory 编译期拷贝和 copyNotNull；补充具体业务含义的中文注释。Google Checkstyle、Spotless 和前端 Prettier 通过。 |
| 第二轮口试材料 | 两份说明书增加 GRASP 职责分配、两套实现差异、Java Web 技术和实际测试方法追溯；另附逐步演示脚本。 |
