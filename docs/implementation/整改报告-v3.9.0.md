# v3.9.0 课程系统联调

课程网页继续使用既有入口。权限后端允许该网页的 Origin 访问 `/auth/**`。浏览器预检由 Spring Security 的 CORS 配置处理，正式业务请求继续校验 JWT 和 RBAC。线上分别验证了界面许可、部门列表、部门成员三个接口的预检、已授权请求以及缺少令牌时的响应。 [课程网页](http://113.44.144.119/course/) [权限后端基址](http://113.44.144.119)

远程权限库保留原有演示账号，导入数据中的总公司 190 人获得本部门的 `teacher` 角色，其余 9,810 人获得本部门的 `student` 角色，两种角色都授予课程登录许可。课程库工号或学号与平台用户名一致，统一身份编号与平台用户主键一致。课程权限目录有 34 项，包括 16 个独立界面许可。管理菜单与按钮由各自的界面许可控制，业务请求继续检查 API 许可或课程归属。 [部署与导入说明](../../deploy/README.md)

课程应用沿用老师仓库 `990cea2` 的前端，以仓库后端加本项目接入补丁构建服务器镜像。教师和学生均可从「我的课程」进入演示课。课程负责人可看教学班，已选课学生可读开放课程的里程碑。规模名册均已绑定身份，演示课关联一名教师和一名学生。审核员可在添加教师时按部门选取统一身份，普通教师的管理菜单禁用，直接进入教师管理页时显示「无法访问」。 [老师的课程仓库](https://gitee.com/mingqcn/course-project-mgt) [网页验收步骤](第二轮演示脚本.md)

平台后端 39 项、CloneFactory 5 项、平台前端 3 项、课程后端 497 项、课程前端 56 项测试通过。线上验证记录包括两套实现的 HTTP 检查、数据库核对、浏览器操作和公网复测。公开 API 文档共 29 项操作，其中 8 项是课程接入所用的统一身份契约。 [测试汇总](test-summary-v3.9.0.json) [部署与联调记录](deployment-v3.9.0.json) [Apifox](https://3wq8lbigke.apifox.cn/) [Swagger](http://113.44.144.119/api-docs/)

结构化和 DDD 各通过 100 项线上 HTTP 检查。首次压测时权限容器触及 384 MiB 上限并被 Swarm 重启，1,000 次请求有 100 次返回 502 或 504。容器上限调至 512 MiB 后，两套实现各以 8 并发计时 1,000 次，结构化 P95 为 165.16 ms，DDD 为 168.53 ms，两轮请求全部返回 200。两套实现验收完成后，Swarm 恢复默认的结构化配置。 [公网实测](deployment-v3.9.0.json)

概要设计和详细设计同步更新，新增跨域预检与学生查询课程两张时序图，更新师生登录时序图和部署图。详细设计将交互图放在对应功能说明下。两份 PDF 均为 A4 纵向，黑白图稿使用同一套 StarUML 可编辑模型。 [设计交付目录](../redesign/README.md)
