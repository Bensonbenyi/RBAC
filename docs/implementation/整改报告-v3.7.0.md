# v3.7.0 整改与验收

平台保留角色新建、重命名、删除、授权、撤权和继承。用户页面提供本部门账号查询与角色分配。账号和部门通过 SQL 维护，部门页面按上级编号显示可折叠的树。平台保留业务系统登记与删除，权限目录继续支持重命名。

两套实现通过 `BACKEND_STRATEGY` 切换，共用三个目录服务。结构化服务组织授权与继承检查，DDD 通过 `User` 校验角色分配，通过 `Role` 校验继承。环路判断与有效权限读取复用同一套继承遍历。新增关系使用 POST，组合主键拒绝重复请求并返回 409。前端提交期间禁用操作按钮。撤销关系重复执行返回 204。课程演示采用单人操作，写入使用常规事务。

业务数据库为八张表，另有一张技术会话表。Flyway V5 删除会话表里重复的系统标识和停用的管理操作权限码。已验签的 JWT 决定目标系统，数据库会话记录账号、到期时间和撤销状态。本地从 v3.6.2 升级，旧版签发的会话在升级后仍能通过验证。

课程管理系统固定在老师提交 `990cea2`。原版 Vue 前端调用课程 `POST /login`，课程后端校验本地工号后调用平台认证。课程页面的权限检查通过同源代理访问平台。平台实现统一身份鉴权的八个接口。教师示例仓库核对到 `38fd817`，CloneFactory 版本为 0.0.2，使用编译生成的拷贝代码。 [课程仓库](https://gitee.com/mingqcn/course-project-mgt) [Spring 教学仓库](https://gitee.com/mingqcn/spring-fundamentals)
