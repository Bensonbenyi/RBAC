# 绘图规范与参考 v3.4.0

图稿使用黑白 UML 和陈氏 ER 表示，页面统一 A4 纵向。正文使用 V2 的宋体、黑体、字号和用例表蓝灰配色。

| 依据 | 使用内容 |
| --- | --- |
| [OMG UML 2.5.1](https://www.omg.org/spec/UML/2.5.1) | 类、接口、关联、多重性、依赖、实现、活动、状态、包、部署和交互语义 |
| [StarUML 官方文档](https://docs.staruml.io/) | 模型与视图的可编辑组织 |
| [老师课程仓库](https://gitee.com/mingqcn/course-project-mgt)，固定 ca90f1c | API、Service Port、Service、Infrastructure 四层及图种 |
| 用户提供的《5. 面向对象设计》 | 对象职责、领域对象、核心设计类与分层协作 |
| [SemVer 2.0.0](https://semver.org/lang/zh-CN/) | 当前版本 3.4.0，修订按三段版本号管理 |

陈氏图使用矩形实体、椭圆属性、下划线标识属性、菱形关系和基数；表关系图标注主外键及乌鸦脚多重性。会话作为独立技术表展示。

类图分别展示边界、控制、领域对象、接口和依赖；概要类图保留主要属性及关键行为。包图保持包粒度，详细类图按模块单列。实线表示关联，虚线开箭头表示依赖，虚线空心三角表示接口实现。

交互图以向下的时间顺序排列，同步调用用实线实心箭头，回复用虚线开箭头。功能下的图列出实际服务、权限检查和存储调用，事务与错误规则写在邻近说明。系统级故事图以模块为生命线，并标明故事、效用树叶节点与需求编号。

图稿生成时检查模型 ID 和引用；SVG 审核检查文字边界和正文图片路径；PDF 导出检查图片加载及目录页码。发布前将全部页面渲染为图片，核对字体、表格、分页和图中文字。

本版完整保留 v3.2.2 样式基础。时序图最大高度为 210 mm，详细模块、领域与包图最大高度为 210 mm；采用相同图幅阅读约定。模块图投影方法名称，输入输出在相邻功能调用说明中展开。

老师新版 `docs/backend-design.md` 第 17 节要求成员字段使用关联，临时使用采用依赖；服务交互与持久化适配器分图。回复不编号，各次调用独立显示执行说明；领域对象头部位于创建消息处，CloneFactory 静态生命线标注 `«MetaClass»`。
