2026-11-12 下载并查阅了 OMG 正式规范 PDF。StarUML 官方部分教程页面返回访问限制，符号核对以 OMG 正式规范为准。老师示例用于参考职责拆分和图的组织，业务模型以本项目确认需求为准。

## 本版表示约定

类图在模块视图中展示相关操作，领域完整状态由正文职责表列出。虚线开箭头表示依赖，接口实现采用虚线空心三角；字段引用使用关联。图中接口实现为两套服务的设计关系，启动配置每次只装配一套。

顺序图按具体操作展开，复杂交互拆成公共请求校验、对象拷贝和具体业务交互。每张业务写图引用公共前提，展示服务事务、数据加载、规则校验、写入和返回。DDD 对象创建后才执行领域行为。异常 break 框展示终止路径，数据库提交冲突和依赖故障按正文统一错误规则处理。

同一查询对两套实现使用相同端口交互图；写操作分别画结构化和 DDD 图。顺序图中的 Store 是具体资源的数据访问端口，loadForChange 只返回本次需要的对象、关系和引用信息。操作资格与数据范围由服务校验。

## 检查记录

生成工具检查原生模型 ID 唯一、引用存在、调用消息绑定操作签名，以及每个接口都有对应图。PDF 导出检查图片加载和目录页码；发布检查全部页面的尺寸、方向及渲染结果。图形预览采用显式坐标，原生模型保留可编辑 UML 元素。
