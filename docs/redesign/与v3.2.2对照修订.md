## 与实现保持一致

数据库关系采用用户角色、角色权限两组多对多；用户和角色均归属单个部门。平台自身与老师课程系统分别登记为接入系统。登录使用 username、password、systems，password 承载手机号；成功后签发 Bearer JWT，并在 MySQL 保存技术会话。每次请求读取当前授权。

结构化和 DDD 共用 API、Service Port 及 Infrastructure，通过 BACKEND_STRATEGY 启动选择。持久化采用 Spring JDBC，旧图中的 JPA Repository 和 PO 按当前实际实现改绘。性能实测、四个架构故事、部署与追溯内容保留。
