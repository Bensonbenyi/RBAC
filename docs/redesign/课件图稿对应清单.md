| --- | --- |

| DDD 模块类图 | `class-ddd-user/role/department/system/permission` |
| DDD 领域对象类图 | `domain` 展开实际状态与行为，`domain-relations` 表达核心关系及多重性 |
| 总体分层架构 | `architecture` |

| 系统包图 | `packages` 总览、`packages-structured/ddd` 分层、`packages-full-structured/ddd` 完整包图及四张入口、实现依赖分图 |

平台全部 38 个 HTTP 操作有交互图。结构化与 DDD 的业务操作分别绘制，认证共用；课程所选 7 个业务接口和 GET /me 支撑接口另列交互。图稿以人工坐标排版，保留 UML 模型元素。

对照 v3.2.2 的 90 处图引用，89 处由当前图稿覆盖，原 CSRF 图按 Bearer 契约替换。见 [对照修订记录](与v3.2.2对照修订.md)。

本轮补充 `class-selection` 只读授权候选查询类图、`flow-ui-api` 独立界面与 API 决策图，以及九张 DDD 聚合修改续图。当前共 137 张 UML 及架构图，另有三张 ER、业务表和会话表图，共 140 张。
